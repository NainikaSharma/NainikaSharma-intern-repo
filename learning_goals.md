# What I Want to Learn & Contribute

## What do I hope to learn from this internship?

I hope to gain practical experience working as part of a real software development team and understand how professional software is designed, developed, tested, reviewed, and maintained. I am particularly interested in learning how frontend development works in a production environment, including working with an existing codebase, following coding standards, using version control effectively, and contributing through a structured Agile workflow.

Through Focus Bear, I also hope to better understand how a productivity application is developed and improved based on user needs. I want to learn how features such as distraction blocking, focus sessions, routines, and habit-building tools are translated into a simple and effective user experience.

## What skills am I most excited to develop?

I am most excited to develop my frontend development skills, particularly using React and related technologies. I want to improve my ability to build clean, reusable, and user-friendly components while working with an existing application rather than only building projects from scratch.

I am also excited to develop my skills in testing, debugging, Git and GitHub workflows, code reviews, and Agile development. Through contributing to Focus Bear, I want to gain more experience identifying UI issues, understanding user journeys, improving usability, and testing features from the perspective of a real user.

In addition, I am interested in learning more about secure and reliable software development and how security, privacy, accessibility, and performance can be considered when developing user-facing features.

## What do I think I can contribute to the team?

I believe I can contribute to Focus Bear through frontend development, testing, debugging, and improving the user experience. As a software engineering student with experience in programming and problem-solving, I can contribute to implementing and improving React components, investigating bugs, and testing changes before they are released.

I can specifically contribute by reviewing the Focus Bear app from the perspective of a new user and identifying areas where the onboarding process, navigation, instructions, permissions, or feature explanations may be confusing. I can document these issues clearly and suggest practical improvements to make the experience easier for new users.

I can also contribute to improving existing features by:

* Testing frontend features and identifying bugs, unexpected behaviour, or edge cases.
* Fixing smaller frontend issues and improving existing React components.
* Helping improve the clarity and usability of onboarding flows.
* Reviewing the user experience for productivity features such as focus sessions, routines, distraction blocking, and habit-related tools.
* Writing or improving tests to help ensure changes do not break existing functionality.
* Investigating technical issues and debugging problems systematically.
* Contributing through GitHub by creating clear commits, working on assigned tasks, and following the team's development workflow.
* Applying a security and reliability mindset when reviewing code and considering potential issues.

I am also willing to take ownership of tasks, learn unfamiliar parts of the codebase, and use feedback from the team to continuously improve my contributions.

## What is one area I feel less confident in that I’d like to improve?

One area I would like to improve is my confidence working with a large, existing production codebase. I have experience building projects and completing university assignments, but I want to become more confident navigating unfamiliar code, understanding how different parts of the Focus Bear application connect, and making changes without introducing unintended issues.

I would also like to improve my confidence with professional frontend testing and code reviews. I want to learn how experienced developers test React applications, identify edge cases, review pull requests, and provide or respond to constructive technical feedback.

## What does success in this internship look like for me?

Success in this internship would mean becoming a more confident and capable software engineer while making meaningful, concrete contributions to Focus Bear. By the end of the internship, I would like to have contributed to real improvements in the application, such as implemented or improved frontend features, resolved bugs, improved tests, or helped make the onboarding and user experience clearer.

I would consider it a success if I can independently understand assigned tasks, navigate the Focus Bear codebase, make well-tested changes, and contribute effectively through the team's GitHub and Agile workflow.

I also want to finish the internship with stronger React, testing, debugging, collaboration, and secure software development skills. Most importantly, I want my work to provide genuine value to the Focus Bear team and contribute to making the app easier, more reliable, and more useful for its users.
