# **Unit Testing Reflection**

## **Why is automated testing important in software development?**

Automated testing helps developers verify that code works as expected without manually checking every feature. It saves time, improves software quality, detects bugs early, and prevents existing functionality from breaking when new changes are introduced.

## **What did you find challenging when writing your first Jest test?**

The most challenging part was understanding how Jest test files are structured and learning how the `test()` and `expect()`functions work together. Once I created a simple test and ran it successfully, the process became much easier to understand.

## **What I Learned**

* Jest is a JavaScript testing framework used for automated testing.  
* Unit tests help verify that individual functions work correctly.  
* Automated testing improves code reliability and maintainability.  
* Jest provides simple methods such as `test()` and `expect()` for writing tests.
