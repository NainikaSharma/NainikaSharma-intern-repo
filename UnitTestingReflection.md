# Unit Testing Reflection

## How do unit tests help keep code clean?

Unit tests help keep code clean by encouraging developers to write small, reusable, and independent functions/components. They verify that each part of the application behaves correctly and make future changes safer by detecting unexpected issues. Tests also act as documentation because they describe the expected behavior of the code.

## What issues did you find while testing?

During testing, I found that some components required additional setup and dependencies before they could be tested properly. Testing helped identify issues with component behavior, state updates, and dependencies. Writing tests improved confidence that the application works correctly after making changes.
