# VS Code Productivity

## VS Code Setup

I already have Visual Studio Code installed and use it for my development
work. I researched the default Windows shortcuts and selected the shortcuts
below.

## Useful Shortcuts

### Navigation

| Shortcut | Action | Why it is useful |
| --- | --- | --- |
| `Ctrl + P` | Quick Open | Opens a file by typing its name instead of searching through folders. |
| `F12` | Go to Definition | Jumps directly to the definition of a function, class, or variable. |
| `Ctrl + G` | Go to Line | Moves directly to a specific line number in the current file. |

### Editing

| Shortcut | Action | Why it is useful |
| --- | --- | --- |
| `Alt + Click` | Add Multiple Cursors | Adds extra cursors so I can edit several locations at the same time. |
| `Ctrl + D` | Add Next Occurrence to Selection | Selects the next matching word and lets me edit repeated text together. |
| `Ctrl + /` | Toggle Line Comment | Comments or uncomments the selected line quickly. |
| `Shift + Alt + Down Arrow` | Copy Line Down | Duplicates the current line without copying and pasting manually. |

### Debugging

| Shortcut | Action | Why it is useful |
| --- | --- | --- |
| `F5` | Start or Continue Debugging | Starts the debugger or continues execution after it pauses. |
| `F9` | Toggle Breakpoint | Adds or removes a breakpoint on the current line. |
| `F10` | Step Over | Runs the current line and pauses at the next line without entering a function. |

### Terminal Commands

| Shortcut | Action | Why it is useful |
| --- | --- | --- |
| `Ctrl + Backtick` | Show or Hide Integrated Terminal | Opens or closes the terminal without leaving the editor. The backtick key is usually below `Esc`. |
| `Ctrl + Shift + Backtick` | Create New Integrated Terminal | Opens another terminal when I need to run a separate command or process. |

## Reflection

The shortcuts I expect to use most often are `Ctrl + P`, `Alt + Click`,
`Ctrl + D`, `Ctrl + /`, and `Ctrl + Backtick`. `Ctrl + P` will help me move
quickly between files in larger React and software projects. The
multiple-cursor shortcuts will be especially useful when I need to update
repeated variable names, component properties, or similar lines of code.
`Ctrl + /` will make it faster to temporarily disable code while testing. The
terminal shortcut will let me run Git, npm, and other commands without
switching away from VS Code.

Keyboard shortcuts can improve my productivity by reducing repeated mouse
movement and keeping my attention on the code. They make common actions such
as opening files, editing repeated text, commenting code, debugging, and using
the terminal faster. As I practise these shortcuts, I will be able to complete
routine tasks with fewer steps and maintain a smoother workflow.
