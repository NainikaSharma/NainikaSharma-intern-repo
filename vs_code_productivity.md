# VS Code Productivity

I already had Visual Studio Code installed and have been using it for my projects and development work. I researched VS Code keyboard shortcuts and selected the following shortcuts as the most useful for my daily work.

## Top 10 VS Code Shortcuts

### Navigation

| Shortcut           | Purpose                            |
| ------------------ | ---------------------------------- |
| `Ctrl + P`         | Quickly open a file                |
| `Ctrl + Shift + O` | Go to a symbol in the current file |
| `Ctrl + Shift + F` | Search across the project          |

### Editing

| Shortcut             | Purpose                                        |
| -------------------- | ---------------------------------------------- |
| `Ctrl + D`           | Select the next occurrence of the current word |
| `Ctrl + Alt + ↑ / ↓` | Add multiple cursors above or below            |
| `Alt + ↑ / ↓`        | Move the current line up or down               |
| `Shift + Alt + F`    | Format the current document                    |

### Debugging

| Shortcut | Purpose                     |
| -------- | --------------------------- |
| `F5`     | Start or continue debugging |

### Terminal Commands

| Shortcut      | Purpose                               |
| ------------- | ------------------------------------- |
| ``Ctrl + ` `` | Open or close the integrated terminal |

## Reflection

The shortcuts I think will be most useful in my daily work are `Ctrl + P`, `Ctrl + Shift + F`, `Ctrl + D`, and `Ctrl + Alt + ↑ / ↓`. The multiple-cursor shortcut is particularly useful because it allows me to edit several locations at the same time instead of making the same change repeatedly.

Keyboard shortcuts can improve productivity by reducing the need to switch between the keyboard and mouse. They make common actions such as opening files, searching code, editing multiple lines, formatting code, and opening the terminal faster. Using shortcuts also helps me stay focused on the code I am working on and makes repetitive tasks more efficient.
